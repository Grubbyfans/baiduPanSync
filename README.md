- 插件目录：[baidupansync.koplugin](baidupansync.koplugin)（当前版本 0.10.2：WebDAV / 百度网盘进度同步、当前 EPUB 上传、书库下载）
- 安装/使用/测试说明：[baidupansync.koplugin/README.md](baidupansync.koplugin/README.md)
- 阶段 A 验收记录：[阶段A验收记录.md](阶段A验收记录.md)（已通过）
- 阶段 B 验收记录：[阶段B验收记录.md](阶段B验收记录.md)

## 当前状态

0.10.1：点击书籍先打开详情，只有点击详情中的“下载书籍”才启动下载；返回书库不会下载。

当前版本 **0.10.2**，改为按文件名书名识别书籍、同名直接覆盖并保留进度；书库仅使用独立 `library.json`，每天首次进入更新，本机持久缓存封面，并提供“主动更新书库”。百度下载链接缓存 7 小时，上传使用按任务动态域名和分片协议。按单用户交替使用设备设计，不做多设备并发保护。

**本版不兼容或迁移旧云端数据，用户自行清空后从零使用；插件不会自动清空网盘。** 运行说明以 [插件 README](baidupansync.koplugin/README.md) 为准；历史技术方案及旧验收记录描述的是旧实现。新版验证见 [0.10.0验收记录.md](0.10.0验收记录.md)，真机待验收。0.9.6 及此前核心闭环的历史通过结果不代替本版验收。

## 运行测试

```bash
KOREADER_DIR=/path/to/koreader ./baidupansync.koplugin/spec/run.sh
KOREADER_DIR=/path/to/koreader ./baidupansync.koplugin/spec/run.sh --bench
KOREADER_DIR=/path/to/koreader npm --prefix serve run test:plugin
```

## 本地 WebDAV 测试服务

已提供零依赖 Node.js 服务：[serve/README.md](serve/README.md)。修改 `serve/config.json` 的端口、账户和存储目录后，运行 `node serve/server.js`，可测试插件的 C1 上传下载及条件写入。

## 0.10.2 本机唯一书名索引

书库新增“检查本机书籍”，递归扫描 KOReader 根目录及子目录（不跟随符号链接，不扫描插件临时目录及自动备份）。结果持久保存到 `settings/baidupansync/local_books.json`，每个书名只对应一个路径。首次下载或更换根目录后先执行一次检查，平时进入书库只比对两份索引，不扫描文件系统。

发现同名文件时列出全部完整路径，可在“查看完整信息”中阅读；不保存新索引，保留旧缓存，并记录冲突阻止下载，用户删除或重命名后重新检查。取消、失败均保留旧索引。

书库标注“本机已存在”或“下载”；已有书详情提供打开、重新下载和删除本机书籍，删除前确认完整路径，不删除云端数据或本机阅读设置，不能删除当前打开的书。下载完成直接登记路径，删除成功直接移除记录，不重新扫描。同名重新下载只允许覆盖已登记位置，不能另存制造重复。外部文件管理器的更改通过主动检查同步；打开时只核对该路径，缺失则移除标记。

验证：原生 223 项，219 通过、4 项网络夹具/环境测试跳过；离线回归和 Lua 语法检查通过，已渲染检查书库按钮与本机状态布局。真机交互待验收。
