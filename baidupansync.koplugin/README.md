# BaiduPanSync（KOReader 插件）

版本 **0.8.7**，技术方案 V1.8。WebDAV 与百度网盘均已实现手动阅读进度同步、当前 EPUB 上传、封面书库与下载。离线回归通过；真实百度应用、KOReader GUI 与目标设备专项仍待验收。

## 安装

将整个 `baidupansync.koplugin` 复制到 KOReader 的 `plugins/` 目录并重启。升级前备份 `<KOReader数据目录>/settings/baidupansync/`，停止活动任务再替换插件。验证源码基线为本地 KOReader `c3e5f750b`。

“书籍与阅读进度同步”菜单在文件管理器和阅读界面可用。没有打开 EPUB 时，当前书籍操作禁用，云端书库和配置仍可访问。

## 独立插件页面

从 KOReader 菜单点击“书籍与阅读进度同步”，进入独立全屏页面。页面显示服务配置状态与当前书籍，主页提供以下入口：

- **云端书库 · 下载书籍**：直接浏览和下载。
- **上传当前书籍**：直接发布当前 EPUB。
- **阅读进度**：集中查看、上传、下载应用及撤销。
- **关于 · v版本号**：显示正在运行的插件版本及支持的同步方式；无需配置服务或打开书籍，任务运行时也可查看。
- **连接设置**：配置和测试 WebDAV、进入百度授权验证、显式切换后端。

分组页面的“返回主页”和返回键均可回到主页。在主页再次返回才退出插件页面。任务执行时仍可浏览分组，不能重复启动操作或修改连接。

配置保存/取消、查询或同步结果关闭后仍回到同一个主页。云端书库下载时保留列表及当前页，可继续选择下一本；点击“返回插件主页”回到主页。只有主动关闭主页、关闭文档或选择打开书籍时才退出对应页面，不会在异步任务结束后自动重新弹出已关闭页面。未打开 EPUB、未配置服务或任务执行期间，不可用的操作置灰。

## 配置与连接

1. 进入“连接设置 → 配置 WebDAV”，填写完整同步根 URL、用户名和密码。可选 CA 文件留空时使用系统可信 CA。
2. 在同页选择“测试连接”。它使用随机命名的专用 JSON 验证读写、枚举、条件创建/替换和条件删除；不修改实际书籍。
3. 每次会话首次写入未确认能力时，会执行同类探测。服务器根目录需要预先存在，插件建立 books、metadata、progress 子目录。

HTTP 明文传输仅用于用户明确配置的可信局域网。HTTPS 强制校验 CA、证书链、有效期和 SAN DNS/IP；缺少 CA、错主机或证书无效会失败，不自动降级。CN-only 证书不支持。

配置和密码分开保存，密码文件受 POSIX 权限保护，并非加密存储。更改目标或账户改变 backendId，进度基线不会混用；更新同一身份的密码不重置基线。任务进行中禁止修改配置或启动其他任务。

## 百度授权与使用

1. 进入“连接设置 → 百度网盘授权与验证 → 手机扫码配置与授权”。首次使用无需先配置应用，阅读器直接显示二维码。手机扫码后填写 AppKey、SecretKey 和实际应用目录 `/apps/应用名称`，点击“保存并继续授权”，即可在同一入口继续完成百度授权。已有应用的 AppKey 和目录可预填，SecretKey 不会回传或回显；同一 AppKey 下密钥留空可保留原值，改用其他 AppKey 时必须填写新密钥。
2. 如需手动指定阅读器 IP 或 CA 文件，可选择“在阅读器配置应用”；这些字段不从手机表单修改。已有应用也可直接选择“使用现有配置授权 / 重新授权”。
3. 打开扫码入口后，阅读器会临时监听单个局域网 IP 的随机端口，显示有效 10 分钟的二维码；手机与阅读器须在同一 Wi-Fi，路由器不能启用客户端隔离。自动检测 IP 不正确时，在配置中手动填写。
4. 手机扫码打开页面，点击“前往百度授权”，在新标签页完成百度授权并复制授权码；回到局域网页面粘贴并提交。也可使用阅读器页面的输入框作为备用。授权请求和兑换请求都使用 `redirect_uri=oob`，局域网页面不是百度回调地址。应用是否允许 OOB 需以实际授权结果为准。
5. 阅读器通过验证证书链和主机名的 HTTPS 连接换取凭据，确认返回的 `netdisk` 权限、有效期和精确用户 UK 后保存；阅读器不向手机返回 Token 或已保存的 SecretKey。成功状态供手机查询最多约 5 秒，随后关闭服务；取消、断网、地址变化或超时也会关闭。出现失败时在阅读器重新开始，不自动重复使用授权码。
6. 选择“验证测试文件上传与下载”，在应用目录内创建 `c2-probe-随机值/probe.json`，依次验证身份、建目录、预创建/分片上传/提交、枚举、HTTPS dlink 下载、内容回读和删除。失败时提示随机测试目录供人工核对，不自动重试提交。成功后空测试目录保留。
7. 在“切换同步后端”显式选择后端。百度选项需授权未过期且测试通过；选择后即可从主页上传当前 EPUB、打开云端书库或同步阅读进度。任务固定使用启动时的后端，切换后需重新打开书库。各后端凭据与基线保持独立，切换不迁移数据。

应用密钥和授权码经局域网 HTTP 提交，不加密，应仅在可信 Wi-Fi 使用。随机会话地址和 CSRF 凭证用于限制访问，不替代加密。手工复制的 OOB 授权码无法自动验证百度回调 `state`，须由本人从官方授权页复制。页面不加载第三方脚本或统计资源，不将授权码持久化到浏览器。

应用密钥和 Token 保存在 `settings/baidupansync/baidu_credentials.json`，目录请求 0700、文件请求 0600 权限，并通过同目录临时文件原子替换；这不是磁盘加密。旧凭据在授权、身份校验或保存失败时保留。保存 Refresh Token 但本阶段不自动刷新，过期或撤销后重新授权。请勿提交此文件到 Git 或发送到聊天。

该入口不等于百度书籍同步已通过验收。还需在真实应用和目标设备检查应用资格、权限、CA、浏览器表现及 API 限制，详见项目根目录的 `阶段百度DEF验收记录.md`（授权基础见 `阶段C2验收记录.md`）。

### 百度文件位置与限制

以配置的实际应用目录 `/apps/应用名称` 为根目录：

- `books/<完整SHA256>.epub`：书籍原文件。
- `metadata/<完整SHA256>.json`：中文书名、显示文件名、封面缩略图和校验信息。
- `progress/<完整SHA256>.json`：阅读位置、设备、修订与写入标识。

授权连接测试仅操作独立的 `c2-probe-随机值/` 目录。现有 WebDAV 数据不会自动迁移到百度。

当前支持非空、最大 1 GiB 的 EPUB。上传使用预创建、4 MiB 分片上传、提交接口，读取缓冲不超过 64 KiB；上传后再次下载整本书核对 SHA-256，通过才发布书库记录。此校验会额外消耗下载流量、时间和设备临时空间。下载也验证整书摘要，成功才安装；下载书籍不会自动应用阅读进度。

百度不提供本插件所需的原子条件写入。进度和同一书籍的元数据更新会先后检查远端版本并回读，仍不能保证多设备同时写入安全；请错开上传同一本书的进度。远端变化会重新要求确认。不同内容同名书籍仅允许另存名称，不自动删除旧版。未确认的写入不会自动重试，未验证的结果不推进同步基线。上传文件提交成功但后续校验失败时，可能留下没有发布记录的原文件。

### 提示“没有可用的可信 CA 文件”

升级时请复制整个插件目录，包括 `resources/`。0.7.2 起在 CA 字段留空时依次尝试 LuaSec 提供的 CA、KOReader 的 `data/ca-bundle.crt` / 旧 Turbo 证书路径、插件自带 Mozilla 公共 CA 包，以及常用系统路径。较旧 LuaSec 没有 `get_system_ca()` 也可使用后备包。

若曾手动填写 CA 路径，请修正为实际文件，或清空后保存再扫码。错误的显式路径不会自动回退。自定义私有 WebDAV CA 仍使用显式路径。始终验证证书链和 SAN 主机名，不关闭 TLS 验证；设备时间错误、过旧 TLS 库或证书不匹配属于不同错误，不能由添加根证书自动解决。证书包来源、校验值及许可证见 `resources/README.md`。

## 阅读进度

- **上传当前阅读进度到云端**：只对当前 EPUB。确认弹窗显示本地/云端位置、远端版本和目标。确认后重查，变化则再次确认；回读成功后保存基线。
- **查询云端阅读进度**：只读显示云端位置、修订、设备及设备时间；不导航、不改基线。
- **下载并应用云端阅读进度**：完整摘要、大小、格式必须匹配。确认后先保存恢复点再导航，校验引擎实际位置，成功才提交基线。
- **撤销上次进度恢复**：重新确认完整内容身份后回到恢复前位置；不上传云端。旧无完整摘要恢复点保留但拒绝应用。

revision 只用于展示，以远端原始字节 SHA-256 判断变化。弱 ETag 不会转换成强条件；只能尽力写入的服务会先明确告知并要求确认，无法保证消除并发覆盖。百分比只显示，不代替 XPointer。滚动模式拒绝仅凭同页成功。

## 上传当前 EPUB

仅上传当前打开的 EPUB，不扫描批量上传书库。`bookId` 等于完整文件 SHA-256；改名/换路径不改身份，内容字节变化产生新身份。

无同名记录直接上传；发现云端同名或相同内容记录时，显示 bookId 比较结果，再选择取消、覆盖指定条目或重命名。相同内容只保留一份发布记录，重命名改变展示文件名。不同内容覆盖会先发布新 bookId，再条件撤下指定旧条目；旧 EPUB 和旧进度保留，需自行在服务端核对清理。不支持可靠条件删除时，请选择重命名。

EPUB 提交后最后发布 sidecar；发布失败不作为正常书库项。已有 EPUB 但缺少发布记录时，再点上传会提示“检查并补全发布”，回读整本书校验后恢复；矛盾数据会停止。

上传时自动提取不超过 240×320、32 KiB 的灰度 PNG 缩略图，作为可选字段随发布记录同步；封面浏览无需额外下载 EPUB。缩略图提取失败不阻止书籍发布。旧记录可在原设备重新上传以补充封面；原有 EPUB 会先核验内容，不创建相同内容副本。封面损坏或缺失时使用书名占位。

首次发布默认记录 verificationLevel=size，表示已确认提交大小，不宣称验证了服务端完整 SHA-256；补全发布会回读并计算完整摘要。上传书籍不会隐式上传阅读进度。

## 云端书库与下载

1. 在 KOReader 文件管理器设置**根目录**。插件直接读取 `home_dir`，不使用设备默认目录或 `.` 回退。
2. 打开“云端书库 · 下载书籍”，进入全屏封面书架。竖屏三列三行（每页 9 本），横屏四列两行；封面下显示中文书名，没有封面时显示书名占位。点击封面下载，长按查看完整书名、文件名、大小与版本。顶部搜索支持书名或文件名，“排序 / 信息”提供排序和异常记录信息；底部支持首页、上一页、下一页、末页，亦可左右滑动翻页。下载后保留页码和搜索条件。
3. 根目录和子目录中没有同名书籍时，直接下载到根目录。
4. 有同名书籍时，只计算候选的完整摘要，显示所有路径及一致/不同结果，再选择取消、覆盖指定路径或重命名下载。

扫描、哈希和网络传输均提供取消；下载写入任务独占临时文件，检查空间、大小及完整 SHA-256 后安装。禁止覆盖当前打开的书籍；确认后目标或远端版本变化会停止。

覆盖会保留旧 EPUB 备份。不同内容覆盖还会原样备份旧 KOReader 阅读设置，不执行或改写其 Lua 内容；备份路径在完成提示中显示。启用 hash 元数据存储时，需先重启 KOReader再打开同路径的新内容，避免内部旧路径缓存。备份不自动删除；恢复时应关闭相关书籍，核对备份来源再手动还原。

下载后只询问是否打开，不自动应用云端进度。打开后需手动执行进度下载。

## 本地状态

已移除本地进度 JSON 导入、导出功能。升级不会删除原有 `settings/baidupansync/exports/` 备份文件；插件不再创建或读取这些备份。

配置、内容身份缓存、云端进度基线和恢复点仍保存在 `settings/baidupansync/`。云端进度应用后的“撤销上次进度恢复”继续可用。

## 限制与验收

- 只支持 EPUB，不同步书签、批注和排版设置。所有操作由用户手动触发。
- 不关闭或改写内置 KOSync 配置；同时使用其自动同步可能导致额外上报。
- 网络工作在可取消子进程，流式传输带进度显示；socket 10 秒、传输 120 秒预算，DNS 等底层阻塞不保证精确总超时。写入取消表示结果未知，不代表远端回滚。
- JSON 最大 64 KiB，DAV/内存响应最大 1 MiB；大 EPUB 流式传输。过大的目录响应安全失败，不当作空书库。
- 不支持跨文件/跨进程事务；下载发布使用独占预留和同目录 rename，避免覆盖已占用路径，但其他程序不能在极小发布窗口内恶意替换目标。
- 缓存按路径/大小/mtime 失效，不能保证检测保留这些属性的任意外部篡改；重要读写另有完整摘要及流校验。
- GUI、Voyage/Clara BW 真机、真实大书性能和实际公网服务专项仍需验收。详见仓库 `阶段DEF验收记录.md`。

## 开发验证

完整插件验证需要已构建的 KOReader LuaJIT/busted 运行环境。独立回归可运行 `python baidupansync.koplugin/spec/run_isolated.py`（需要 lupa），覆盖百度授权/API/凭据/HTTP 协议，以及封面边界和资源释放、网格布局、搜索排序、翻页及下载确认；真实局域网 HTTP 回归可运行 `python baidupansync.koplugin/spec/run_baidu_lan.py`，仅使用夹具授权码并在结束后关闭监听。它们不替代 KOReader 原生绘制或真实百度应用验收。

```sh
# 普通用例；缺少服务时明确跳过网络用例
KOREADER_DIR=/path/to/koreader ./baidupansync.koplugin/spec/run.sh
# 自动创建 Python HTTP/TLS 隔离夹具
KOREADER_DIR=/path/to/koreader python3 baidupansync.koplugin/spec/run_network.py
# 使用项目 Node 服务（临时目录）+ TLS 夹具 + 全部插件测试
KOREADER_DIR=/path/to/koreader npm --prefix serve run test:plugin
# Node 服务自身的文件/并发/中断测试
npm --prefix serve test
```

本次完整插件测试 **186/186 通过**（23 个文件，无跳过），含真实 Node WebDAV、真实 crengine 的书籍/进度/撤销流程；Node 服务 10/10 通过。桌面自动测试不等于真机验收。


## 删除云端书籍（0.8.1）

在云端书库长按书籍封面，选择“删除云端书籍”。确认框会列出书名、服务位置和关联文件；确认后删除该书的云端 EPUB、metadata 书库记录以及 progress 阅读进度，并刷新书库。本机已下载文件、当前位置及恢复点保留。取消不会删除任何文件。插件内不能撤销云端删除。

WebDAV 需要通过条件删除能力测试，所有已存在的目标文件都必须提供强 ETag，并通过 If-Match 删除；不满足时拒绝执行。百度按已确认的文件版本重查后调用同步 filemanager 删除，再检查目标消失。百度没有原子条件删除，确认框会提醒避免其他设备同时上传/修改同一本书。

多个文件的删除不是事务：执行前重查所有版本，每个删除前再次检查，远端变化时停止。若已经删除部分文件后失败、取消或响应不确定，会明确提示未全部确认及已删除路径，不自动重试。书库可能显示异常记录，应根据提示到对应服务核对剩余文件；不把部分删除报告为成功。原有进度基线保留，后续同步会检测云端进度已不存在。

本次隔离回归覆盖双后端删除、取消、确认期间版本变化、后端不匹配、部分失败、WebDAV 强 ETag 请求和书库入口。真实服务和阅读器 UI 验收仍待完成。


## EPUB 已在百度网盘，但插件提示任务异常（0.8.2）

EPUB 提交成功后，插件仍需下载整书校验，最后发布 metadata 书库记录。网盘里有 EPUB 不代表发布已完成。发现“已有 EPUB 但未发布”时，可在修复失败原因后重新上传，选择“检查并补全发布”：重新校验远端原文件，成功后只补写发布记录，无需先删除 EPUB 或重新传输原文件。

0.8.2 修复下载子进程没有返回结果时，继续访问空结果导致通用 Lua 异常的问题；捕获子进程异常，清理进度窗口和临时状态。新建的空下载文件跳过系统截断接口；有内容的跳转重试仍须成功清空原文件描述符，失败明确报错，不重新创建可能已取消的路径。

校验失败会显示准备临时文件、空间检查、回读下载或整书 SHA-256 中的具体阶段、云端路径和原因。未知 Lua 异常显示代码文件和行号及固定类别，不显示可能含密钥的原始异常。仍不跳过完整摘要校验，也不把未完成的发布报告为成功。

该兼容性及错误处理修复已通过 Lua 5.5 和 LuaJIT 2.1 隔离回归，包括“EPUB 已上传 → 回读无结果 → 保留未发布文件 → 再次补全只上传 metadata”的完整过程。设备实际失败原因还需结合升级后的具体提示或 KOReader 日志确认。


### 日志提示 missing declaration for symbol ftruncate（0.8.3）

用户提供的 Kobo / KOReader v2026.03 日志确认，旧插件在 dav_transport.lua:68 调用 ftruncate 时缺少 FFI 声明，导致上传后的回读子进程退出。0.8.2 已让新建空文件跳过截断；0.8.3 进一步在需要清空非空临时文件时，按 KOReader 原生 off_t 类型补充函数声明，兼容下载跳转重试，不猜测 32/64 位长度类型，也不重新创建可能已被取消的临时路径。接口仍不可用时明确报错并保留完整校验。

请替换整个插件目录，重启 KOReader，并在插件主页确认版本 0.8.3；重新上传后选择“检查并补全发布”。不必删除网盘中已有的 EPUB。


### 补全发布后窗口消失，书库仍无记录（0.8.4）

0.8.4 将任务错误和书籍发布结果改为手动关闭，绕过静默通知并清理积压触摸事件，避免原来的 8/10 秒提示消失或结果被意外点击关闭。回读窗口改为“正在校验已上传书籍”，它属于发布前校验，不是向本机书库安装书籍。

crash.log 新增 BaiduPanSync 标记，记录插件版本、后端类型、操作、书籍大小、状态/阶段和成功或失败原因。不会输出请求 URL、Token、SecretKey 或原始网络响应。排查时核对操作时间与版本，提供本次任务的 BaiduPanSync 日志或完整错误截图即可，不必导出全部历史日志。

本轮仅确认结果提示与诊断缺失的问题，尚未确定用户这次旧书补全失败的底层原因；收到的文件仍只包含旧 ftruncate 错误。新增延迟确认、排队网络回调、逐步哈希和每个事件强制 GC 的补全回归，成功后仅写 metadata，完整摘要校验仍保留。没有据此声称真实设备补全已成功，也没有改用未验证的服务端 MD5 或自动覆盖原文件。


### 回读报“连接或传输未完成”（0.8.6）

0.8.6 修复独立 TLS 套接字在握手后仍沿用 5 秒短超时的问题。现在握手上限为 30 秒，完成后恢复当前请求的读写等待上限；书籍分片/流式传输无数据等待上限为 60 秒，总时限按传输大小计算，至少 300 秒，最多 3600 秒。小型 JSON 请求采用 15 秒等待、120 秒总时限。操作仍可主动取消。

网络错误不再统一提示检查 CA。会按超时、远端提前关闭、大小超限、磁盘写入或证书问题给出固定类别，并显示阶段、已接收字节数、耗时及有效时限，不展示下载签名地址或原始错误中的密钥。遇到真实证书错误仍拒绝连接，不降级 HTTPS。失败后保留网盘 EPUB，可重新选择“检查并补全发布”。

用户本次日志确认 4,425,454 字节的旧书在回读约 54 秒后因网络传输失败，尚未进入摘要校验。日志没有底层 socket 错误，因此不能断言这次失败仅由短超时导致。已修复可确认的超时缺陷，Lua 5.5/LuaJIT 回归通过，设备结果待复测。


### Kindle 扫码地址不可访问，但 FileBrowserPlus 可访问（0.8.7）

同一 IP 的其他服务可访问，并不表示本次随机授权端口已被 Kindle 防火墙放行。0.8.7 在检测到 Kindle 后，为已绑定的阅读器 IPv4 地址和随机 TCP 端口插入两条 INPUT/OUTPUT 规则，只覆盖本次服务的端口和连接状态，不改变防火墙策略。Kobo 和其他非 Kindle 设备不运行防火墙命令。

取消、10 分钟超时、网络变化、授权成功或失败结束时，关闭监听并移除本次插入的规则；开启中途失败会回滚已加入规则。子进程只关闭继承的套接字，不删除父进程仍在使用的规则。设备必须具备可用 iptables 和运行权限，不能放行时直接提示，避免显示无法访问的二维码。异常强退或设备掉电时无法保证执行退出清理，遗留规则只对应已关闭的随机端口，未持久化，重启可清除。

升级整个插件目录并重启，在“关于”确认 0.8.7。重新打开手机扫码配置与授权，使用新生成的完整地址（包含端口），保持授权页开启；旧二维码不会复用。无需占用 FileBrowserPlus 的 80 端口。请继续在同一可信 Wi-Fi 使用。
