# BaiduPanSync

版本 **0.10.7**。KOReader 的手动 EPUB、书库和阅读进度同步插件，支持 WebDAV 与百度网盘。

## 当前数据规则

当前使用 0.10.x 的云端结构，**从 0.10.x 升级无需清空现有列表、书籍或进度**。仅 0.10.0 之前的旧结构不兼容，历史升级由用户自行处理；插件不会代为清空网盘，凭据仍可沿用。本版本需要重新进行真机验收，历史版本的真机通过记录不代表新版已验收。

- 文件名去掉 `.epub` 扩展名作为书名；书名主体区分大小写，判重时忽略扩展名大小写。外部 EPUB 保留实际文件名和扩展名。不读取 EPUB 内部标题判重。
- 同名认为同一本书，直接覆盖，不比较内容，不询问云端重命名。改文件名视为另一本书。
- 不计算 EPUB SHA-256，不整书回读；百度分片协议必需的 MD5 保留。下载检查大小，不声明完成内容摘要校验。
- 同名覆盖保留云端阅读进度，本机下载覆盖也保留阅读设置；旧进度是否仍能被新内容解析，由阅读器实际跳转结果决定。
- 按单用户、同一时刻仅一台设备更新设计。没有跨设备并发保护、双遍全库扫描、写入前后版本复查或发布后额外回读。

```text
library.json           # 唯一权威书库列表，schemaVersion=2
books/书名.epub        # EPUB 正文
covers/书名.json       # 可选封面缩略图，独立于列表
progress/书名.json     # 阅读进度，schemaVersion=2
```

书名需为有效 UTF-8，不能包含路径分隔符、控制字符、`%`、`<>:"|?*`，不能含首尾空格；云端书籍文件名（含扩展名）上限为 255 字节，以便在目标设备下载。本机已有 EPUB 的索引不套用此云端限制。云端检查发现不支持的名称时逐本跳过并提示具体原因，不自动截断或改名。`library.json` 最大 4 MiB、最多 10000 本书；损坏、未来版本或超限时明确报错，保留原文件，不扫描目录重建。

## 安装与连接

将 `baidupansync.koplugin` 放入 KOReader 的 `plugins/`，重启后进入 BaiduPanSync。主页提供阅读进度、上传当前 EPUB、云端书库和连接设置。

### WebDAV

在连接设置填写最终根目录 URL、用户名和密码。根目录应已存在且可读写。HTTP 可用于可信局域网；HTTPS 保留 CA 和主机名验证，可指定 CA 文件。连接测试使用独立随机临时文件；正常书籍操作直接 GET/PUT/DELETE，不要求条件写入能力。

WebDAV 不需要百度 OAuth、上传域名查询或分片提交。初始化完成后，无封面的上传正常为 GET 列表、PUT EPUB、PUT 列表三次请求；有封面另加一次 PUT。

### 百度网盘

1. 在百度开放平台准备具备网盘上传权限的应用。
2. 进入百度设置，启动手机扫码配置/授权。在同一可信 Wi-Fi 的手机页面填写 AppKey、SecretKey 和实际 `/apps/应用目录`。
3. 手机进入官方授权页，将 OOB 授权码粘贴回临时页面，阅读器交换令牌并核对账户。局域网页面是 HTTP，仅在可信网络使用。
4. 完成“验证测试文件上传与下载”后，显式切换到百度后端。不会自动迁移 WebDAV 数据。

EPUB 和 JSON 均使用 **预上传 → 动态获取本任务 HTTPS 上传域名 → 上传分片 → 创建文件**。不使用单步上传，不写死上传域名，不跨任务复用上传域名。每个分片最大 4 MiB；当前插件 EPUB 上限为 1 GiB。

下载链接在本次 KOReader 进程内按后端/账户/令牌/文件缓存 **7 小时**，适配器重建仍可复用；重启后按需重新获取。覆盖、删除或更换授权会失效对应缓存。链接提前失效时重新查询并重试一次；持续失败后停止，不无限重试。上传响应中的文件 ID 用于后续下载，失效时回退到路径查询。

## 书库与封面缓存

- 列表和封面持久保存在本机 `settings/baidupansync/cache/`，按后端/账户隔离。
- **每天首次进入书库**获取 `library.json`；当天再次进入直接显示本机列表。日期使用设备本地日历，首次无缓存则立即获取。
- 顶部和“管理”菜单中均有 **主动更新书库**，点击立即读取最新列表并枚举 `books/` 当前层的 EPUB，合并外部上传的书籍；只有列表变化才回写，不受日期限制。普通进入与每日自动刷新仍只读列表，不枚举目录。
- 获取失败保留旧列表，不更新成功刷新日期，可再次重试。
- 首次显示某一页时加载该页封面，并持久缓存；重开、翻回已加载页面不重复下载。刷新发现封面版本变化后，只重新加载该书封面。
- 上传前始终读取云端列表；成功上传或删除后同步保存本机列表。写入失败结果未知时提示核对，不报告发布成功。
- 日常浏览只使用独立列表或本机缓存，不读取旧 `metadata/`。手动更新可发现 `books/` 中列表外的 EPUB；不递归子目录，不下载 EPUB 或逐书元数据。名称不支持、同名冲突或文件缺失会汇总提示；正常书继续登记，旧条目、封面引用和进度保留。列表损坏仍报错，不自动覆盖重建。

## 上传、下载与进度

0.10.1：点击或长按书库书籍均打开详情，不自动下载。详情提供“下载书籍”“删除云端书籍”“返回书库”；仅点击下载按钮才启动下载，下载期间保留书库页面和页码。

上传当前打开的 EPUB。上传正文成功后可提取并独立上传封面，最后发布列表；封面失败会显示警告，正文和列表仍可完成。列表提交失败可能留下列表外的 EPUB，可重新上传同名书补全。

下载前设置 KOReader 文件管理器根目录。下载使用同目录临时文件、空间检查和文件大小检查；本机同名文件只允许覆盖已登记位置，不能另存造成重复，覆盖前保留旧 EPUB 备份且不移动原阅读设置，不能覆盖当前打开的文档。备份文件不自动清理。安全下载的本机路径占用与大小/mtime 检查仍保留。

阅读进度提供查询、上传、应用与撤销。进度按书名存取，不因同名 EPUB 内容或大小变化而重新关联。应用前保留恢复点，跳转后核对阅读器实际位置，失败不伪报成功。旧版完整摘要恢复点仍由旧逻辑识别；新版恢复点按书名关联。

云端删除需要明确确认，删除所选书籍的 EPUB、封面、进度，并更新列表；本机文件不删除。多文件操作不是事务，失败可能部分完成，应核对提示并主动更新。取消写入不代表远端回滚。

## 请求数量验证

HTTP 夹具已验证：**20 本与 100 本已有书籍，上传同一本 10 MiB 新书，无封面、目录已初始化、无错误/重定向/秒传时：**

| 百度请求 | 数量 |
|---|---:|
| 核对账户 | 1 |
| 读取列表，链接缓存命中 | 1 |
| EPUB：预上传、域名、3 个分片、创建 | 6 |
| 列表 JSON：预上传、域名、1 个分片、创建 | 4 |
| 合计 | **12** |

列表文件 ID 和下载链接均未缓存时合计 **14**；只有文件 ID 缓存时为 13。上传封面另加 4 次。首次建库还需目录初始化；失败恢复、重定向等会增加请求。以上是测试夹具计数，不是真实百度服务或真机耗时承诺。

## 0.10.2 本机唯一书名索引

书库新增“检查本机书籍”，递归扫描 KOReader 根目录及子目录（不跟随符号链接，不扫描插件临时目录及自动备份）。结果持久保存到 `settings/baidupansync/local_books.json`，每个书名只对应一个路径。首次下载或更换根目录后先执行一次检查，平时进入书库只比对两份索引，不扫描文件系统。

发现同名文件时列出全部完整路径，可在“查看完整信息”中阅读；不保存新索引，保留旧缓存，并记录冲突阻止下载，用户删除或重命名后重新检查。取消、失败均保留旧索引。

书库标注“本机已存在”或“下载”；已有书详情提供打开、重新下载和删除本机书籍，删除前确认完整路径，不删除云端数据或本机阅读设置，不能删除当前打开的书。下载完成直接登记路径，删除成功直接移除记录，不重新扫描。同名重新下载只允许覆盖已登记位置，不能另存制造重复。外部文件管理器的更改通过主动检查同步；打开时只核对该路径，缺失则移除标记。

验证：原生 223 项，219 通过、4 项网络夹具/环境测试跳过；离线回归和 Lua 语法检查通过，已渲染检查书库按钮与本机状态布局。真机交互待验收。

## 0.10.3 缓存状态可见

书库页直接展示列表来源（本机缓存、正在更新或云端最新列表）与最近成功更新时间。更新失败时明确提示仍显示旧列表，可主动更新重试，失败不推进更新时间。已验证 225 项原生测试中 221 通过、4 项网络夹具/环境测试跳过；离线回归、语法检查通过，已渲染检查失败状态布局。

## 0.10.4 上传部分失败补救

正文未确认上传成功时，结果页提供“重新上传书籍”。正文成功但列表发布失败时，按后端保存本机待发布记录（不含凭据），结果页提供“补全书库列表”；重新打开书库也可从待补全按钮处理。补全只读取最新列表、合并已确认的书籍条目并提交，不重传 EPUB，不要求当前打开原书。补全失败保留记录，成功清除；新上传及删除同名书籍会移除失效的旧待发布记录，避免补全旧内容。

验证：229 项原生测试中 225 通过、4 项网络夹具/环境测试跳过；离线回归和语法检查通过。包含重建服务后的恢复、只更新列表的调用计数、失败保留、后端隔离和两类结果按钮。

## 0.10.5 简单任务诊断

书库“排序 / 管理”新增“最近任务诊断”。在本机 `settings/baidupansync/diagnostics.json` 保留最近 20 项已启动任务，记录插件版本、后端种类、操作、结果码、HTTP 请求尝试次数/失败响应数/累计等待时间、列表/封面/百度下载链接的缓存命中与未命中、各阶段耗时和请求数。阶段耗时包含等待用户确认；封面按页加载单独记录，避免混入列表刷新或上传计数。当天直接读取列表缓存时记录零次网络请求。统计不会额外发送请求。

不保存令牌、密钥、用户名、服务 URL、下载链接、书名、阅读位置、正文或原始错误消息；诊断只在本机保存，不自动上传。记录损坏时保留原文件，诊断保存失败不影响业务任务。

最终验证：真实本机 Node WebDAV/TLS 与原生阅读器完整回归 233 项，232 通过，1 项真实局域网地址测试因环境条件跳过；离线回归及全部 Lua 语法检查通过。百度 HTTP 夹具中，20 / 100 本书库上传 10 MiB 新书，诊断计数均与实际 12 次（链接命中）/14 次（冷缓存）一致，不含可选封面上传。新增本机索引与缓存状态已渲染检查；新版真机交互仍待验收。

## 0.10.6 本机扫描命名校验修复

本机索引与云端命名规则分离：本机已经存在的 EPUB 按原始文件名去除扩展名登记，不再套用云端上传的截断、字符替换或长度限制，避免合法的长文件名阻断整个扫描。云端上传路径规则不变；扫描仍只登记 `.epub`（扩展名大小写不敏感），长名称 PDF/TXT 不参与登记或重复书名检查。

验证：235 项原生测试中 231 通过、4 项网络夹具/环境测试跳过；离线回归和全部 Lua 语法检查通过。新增长名称 PDF 忽略、238 字节 EPUB 文件名扫描/持久化/查找/登记回归，未修改用户书籍文件。

## 0.10.7 外部上传发现与精简书库界面

主界面只保留一排“搜索 / 主动更新书库 / 管理”。排序、检查本机书籍、切换后端、补全书库列表、异常详情和最近任务诊断集中到“管理”菜单。缓存来源和最近更新时间仍直接显示，点击书籍仍只打开详情。

手动更新执行：读取最新列表 → 分页检查 `books/` 当前层 → 按书名合并 → 有变化才写列表。仅登记非空且不超过 1 GiB 的 EPUB，不下载正文提取封面，新书使用书名占位。保留 `.EPUB` 等实际路径以及合法的 238 字节等长文件名；超出 255 字节或含不支持字符的名称逐本跳过，结果中列出完整路径和原因，用户在网盘处理后再更新。同名组不任意选取或覆盖，缺失书籍不自动删除列表记录和进度。

更新结果汇总新增、更新、未变化、跳过和缺失数量，可打开完整信息查看异常。扫描失败、重复分页或取消检查时保留原列表；列表提交后取消仍不能承诺远端回滚。百度手动检查会刷新枚举文件的本机下载链接信息，避免外部覆盖后沿用旧链接。
